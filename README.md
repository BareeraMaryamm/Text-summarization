Text-summarization
A CLI-based AI Text Summarizer built with Python &amp; Llama 3.1 via Ollama. Converts long paragraphs into concise 2-3 line summaries with stats &amp; reduction % – fully local, no API cost.

🤖 Project Overview: AI Text Summarizer is a lightweight, CLI-based tool that transforms long-form text into a clear and concise 2-3 sentence summary.

⚙️ Tech Stack: Developed in Python 🐍, powered by Llama 3.1 via Ollama  for 100% local and cost-free inference, enhanced with ANSI color codes  for a structured terminal UI, and utilizing Threading & Itertools  to display a real-time loading spinner  during generation.

🧠 Core Functionality: The tool leverages prompt engineering with low temperature (0.3) and token limit (150) for precise outputs 🎯, automatically strips introductory phrases, and presents the final summary in a formatted box 📦 along with detailed statistics 📊 including original length, summary length, and percentage reduction.

⌨️ Usage: To generate a summary, run the script ▶️, paste the long text into the INPUT section 📋, press Enter ↩️, then press Ctrl+Z + Enter on Windows or Ctrl+D on Mac 💻 to submit, and the system will instantly display the concise summary ✨ with performance stats.
